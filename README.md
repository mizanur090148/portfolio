## 🚀 Overview

A modern, high-performance portfolio engineered with **React 19, TypeScript, and Vite**, powered by bespoke Vanilla CSS design tokens (glassmorphism, micro-animations, dark/light theme toggle, and fluid typography). Zero heavy CSS framework dependencies.

### Key Highlights
- **Role Alignment**: Tailored for Senior Full Stack, Senior Software Engineer, and Tech Lead roles.
- **Enterprise Case Studies**:
  - *Ethos Merch Multi-Vendor & Webhook Engine* (Clicko Digital)
  - *Clinical ePrescription & Healthcare Platform* (iHealthScreen)
  - *Garments Manufacturing ERP Pipeline* (Skylarksoft Ltd.)
  - *Apple Store Management Platform* (Eximsoft Tech)
- **Interactive System Flow Visualizer**: Step-by-step interactive microservices architecture node diagrams.
- **Bento Grid Skills Matrix**: 4 core pillars covering Backend, Frontend, Databases/Queues, and Cloud/DevOps.
- **Interactive Terminal Console**: Embedded CLI console (`$ mizanur --cli`) supporting interactive navigation.
- **Verified Credentials**: Confetti-powered CV download (PDF) and modal document preview.
- **Direct Channels**: WhatsApp direct, live Dhaka timezone clock (`Asia/Dhaka`, UTC+6), and copy-to-clipboard contact channels.
